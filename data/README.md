# Data

| Folder | Committed? | Contents |
|---|---|---|
| `samples/` | ✅ Yes (small files only, < 1 MB each) | Sample CSVs, short texts, tiny audio clips used by lessons |
| `raw/` | ❌ Gitignored | Downloaded corpora (created by notebook cells) |
| `outputs/` | ❌ Gitignored | Generated results, audio, charts, checkpoints. Module 03: `outputs/memory/*.sqlite` (conversations and learner memories: personal data, never commit) and `outputs/scratch/` (the 03.01 autoreload demo module). Module 04: `outputs/m04/` (fake outboxes, audit logs, the 04.06 SQLite pause). Module 05: `outputs/m05/` (notes as UTF-8 JSON per user, `mcp.json` IDE config example, project audit log) |
| `vectorstores/` | ❌ Gitignored | Persisted Chroma and other indexes |

Never commit personal or confidential documents. Use public or synthetic data for anything you'll publish.
