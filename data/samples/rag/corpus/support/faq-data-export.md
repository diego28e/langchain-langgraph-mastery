# FAQ: Exporting your data

## How do I download my readings?
In the web dashboard choose **Export > CSV**. You can export up to **24 months** at a time, the same period we keep raw readings.

## Is there an API?
The REST API is available for **Nimbus Pro, Marine and Agro** stations. See the API reference PDF for endpoints and limits.

## What units are used?
Exports use metric units (°C, hPa, mm, km/h). Convert in a spreadsheet if you prefer imperial units.
